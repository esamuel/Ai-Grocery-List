# 🎁 Quick Start: Add Promo Codes (3 Minutes)

## ✨ Super Simple - No Technical Skills Needed!

### Step 1: Open Your App
1. Go to: **https://aigrocerylists.com**
2. Sign in with your account (must be Owner, not Family Member)

### Step 2: Open Settings
1. Click the **⚙️ Settings** icon (top right corner)
2. Scroll down to the bottom
3. You'll see a green button: **"🎁 Add Promo Codes"**

### Step 3: Add All Codes
1. Click **"🎁 Add Promo Codes"**
2. You'll see a list of 12 promo codes ready to add
3. Click the big green button: **"✨ Add All Promo Codes"**
4. Wait a few seconds (you'll see progress in real-time)
5. Done! ✅

### Step 4: Start Sharing!
Your promo codes are now active and ready to share:
- **BETA2025** - 100% off first month
- **LAUNCH50** - 50% off for 3 months
- **WELCOME50** - 50% off for 3 months
- **FRIEND5** - $5 off first month
- **VIP-INFLUENCER** - 100% off for 6 months
- ...and 7 more!

## 📊 How to Track Usage

### View in Firebase Console:
```
https://console.firebase.google.com/project/grocery-list-ai-1e7a5/firestore/data/promoCodes
```

You'll see:
- How many times each code was used (`currentUses`)
- How many uses are left (`maxUses - currentUses`)
- Which codes are most popular

## 💡 How Users Apply Codes

1. User clicks "💎 Upgrade to Pro"
2. User enters code in "Promo Code" field
3. User clicks "Apply"
4. Discount appears instantly
5. User selects plan and continues to PayPal
